8. 无有效录音：显示重试/文字选择；切文字后之前修改的文本保持。
9. 转写失败：显示恢复操作；重试后得到样例核对页。

### 检查后追加的一次修整

- 发现：body 的 min-width:320px 在有效宽度缩小时造成横向裁切。
- 修复：取消最小宽度，收窄小屏页头。复查266、320、390、430宽度均无横向溢出。
- 发现：提交按钮禁用后，失败时键盘焦点落到页面根部；结束编辑也缺少明确焦点归位。
- 修复：失败聚焦重试，编辑完成聚焦 Edit；浏览器读取 activeElement 已验证。
- 完成静态子目录部署适配，移除 Vite 默认标题/图标和外部字体依赖。
