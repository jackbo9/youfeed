# YouFeed 现场速查｜重建版 v1.1


# 先对对象，帮助表达，明确结束

重建材料；当前版本只做模拟语音与模拟提交。没有确认的信息，不向观众承诺。

01 / 邀请与区域

“我们想了解您对[对象]的看法。愿意的话，可以轻触 NFC 或扫码进入；不参加也完全没关系。”演示时补充：语音用样例，内容不会送出。

| A 整体体验 | P 具体产品 | T 座谈 / 演讲 |

| --- | --- | --- |

| 任选最有感受的一点 | 先确认产品；区分第一印象和使用经验 | 先确认标题 / 场次；谈内容、理解或体验 |

02 / 不知道怎么答时

“您可以只说最有感受的一点。” → “如果愿意，可以说说是什么让您有这个感觉。”
不方便说就选择文字；不想继续就结束。不提示正面答案、不代写、不强迫补充。

03 / 异常：先查 → 替代 → 停止 → 交接

| 现象 | 下一步与停止条件 |

| --- | --- |

| 入口 / 网络失败 | 无内容：核实对象，换同对象已核实入口或网络。<br>一次恢复仍失败就停；已有内容先勿刷新。指南 E1 / E2。 |

| 对象错误 | 暂停填写，核对物料与页面；无正确入口就停。<br>已有内容不承诺迁移；通知负责人停用错配物料。E3。 |

| 语音不可用 | 转文字；当前演示不录音。一次恢复仍失败就停。E4。 |

| 提交失败 / 结果不明 | 只在确认可安全重试时重试一次；不明就不再提交。<br>保留原页，可结束等待；记录“结果不明确”，交后台查。E5 / E6。 |

04 / 收尾与最小记录

记：时间、区域 / 入口、对象、困难、协助与重试次数、最后状态、交给谁。
区分：独立完成 / 协助后完成 / 未完成 / 结果不明确。另记真实接收是否核实。
