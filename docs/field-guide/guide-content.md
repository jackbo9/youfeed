# YouFeed 展会现场运行指南｜重建版 v1.1


# 帮助观众留下自己的看法

使用顺序：展前读 01–03、08；现场查 04–06；记录与交接用 07。

本指南是什么

依据参与者回忆与现有项目资料重新设计的工作人员材料，不是当年原件。三类区域、问题、引导语和处理规则均为本次拟定；当前截图来自后续概念演示。

服务流程 / 最后一段由后台团队负责

工作人员邀请 → 观众进入对应入口 → 表达反馈 → 核对与完成 → 后台团队：企业平台接收和分析

这张图表达服务关系。当前演示只覆盖手机端模拟体验，未采集音频、未发送反馈，也未连接企业平台或 InsightGPT。

邀请话术 / 先说明用途，再给选择

“我们在收集大家对这里的体验、产品或活动的看法。您愿意的话，可以用手机轻触这张 NFC 卡，或扫描二维码，进入对应页面留下意见。不参加也完全没关系。”

各自负责什么

观众：决定是否参与、表达什么、是否修改，以及何时结束。
工作人员：确认对象，解释操作和问题范围；不替观众评价或改写。
现场负责人：核对入口、协调异常、接收记录并安排交接。
后台团队：核实接收状态及系统问题；本指南不展开分析设计。

演示培训前另说：“今天体验的是模拟版本，语音使用样例，内容不会送出。”不承诺匿名、完成耗时、数据保存期限或客户响应时间。

# 邀请 → 进入 → 表达 → 核对

页面用于解释操作。下图是 R7 当前概念演示截图，不是历史现场界面。

[当前 R7 演示截图](../../screenshots/r7-home-390.png)

01  邀请 / 先得到参与意愿

用第 1 节话术。观众拒绝或想结束就停止，不追问理由。

02  进入 / 确认对象

请观众核对产品名或活动名。NFC 不响应时，可用同一对象的已核实二维码；目前仓库未验证实际 NFC / 二维码链路。

03  表达 / 让观众自己选择

圆形 Try speaking 是模拟语音入口；Write a thought 是文字入口。不方便说话可直接写，不必先试语音。

04  核对 / 内容由观众决定

请观众检查是否表达了本意。核对页可 Edit；Continue as text 可继续编辑已有文字。工作人员只解释按钮，不代改评价。

05  完成 / 区分“页面结束”和“真实接收”

当前 Demo complete 只表示演示结束，页面明确说明反馈未送出。真实现场应按已确认的完成提示判断；若状态不明确，不声称成功，也不立即重复提交，转第 6 节。

保护已经写下的内容

当前演示在页内切换时保留已形成的文字；刷新、重启会清空。开始新的模拟语音并生成样例，会替换原稿；看到清空或重录确认框时，先向观众解释后果，由其决定。


# 帮助表达，不替人作答

先听，再用一条提示；观众仍不想补充，就接受其原有表达或结束。

### 01 不知道 YouFeed 是什么
目的：说明用途与参与方式。
可说：“这是一个反馈入口，帮助我们了解您对这里的看法。您可以自己选择是否参与。”
避免：不许诺匿名、固定耗时、奖励或意见一定获采纳。

### 02 不知道该评价什么
目的：确认对象，缩小范围。
可说：“这里对应的是[对象]。您可以只说最有感受的一点，第一印象也可以。”
避免：不把示例答案当提示，不说“可以夸一下设计”。

### 03 “没什么意见”或评价很笼统
目的：给一次自愿补充的机会。
可说：“如果愿意，您可以说说是什么让您有这个感觉；不补充也可以。”
避免：不将“还行”改成正面评价，不反复追问，不要求凑字数。

### 04 不方便使用语音
目的：让文字成为直接选择。
可说：“您可以选择文字输入，按自己的方式写就好。”
避免：不要求先开麦、不代录；模拟版不能说它正在录下声音。

### 05 进入错误产品或活动页面
目的：停止错配，重新确认对象。
可说：“这里显示的是[页面对象]，您想评价的是[目标对象]，对吗？我们先核对入口。”
避免：不在错误页面硬填；不承诺内容可自动迁移。已有内容先告知风险。

### 06 不愿参与或希望结束
目的：尊重退出，结束协助。
可说：“好的，谢谢您，您可以随时结束。”
避免：不劝留、不追问私人原因、不替其完成；不能承诺关闭等于删除已提交内容。


# 先确认对象，再恢复连接

【界面】为当前演示；【待确认】为未验证能力；其余恢复与停止规则为现场拟定。

先判断：是否已填写或点击提交？
尚未填写 → 核对入口 / 网络；已有文字 → 不刷新，先保护内容；已点提交 / 不明 → 不重复提交 → E6

E1 / 网络不稳定或页面打不开

现象｜持续加载、空白、连接错误。

先查｜先问是否已经输入或点击提交；有内容就不要先刷新。确认链接与当前网络状态。

替代｜尚未填写时，可由观众自愿切换可用网络，再打开已核实入口；已有内容或已提交转 E6。

停止｜完成一次有变化的恢复尝试后仍失败，或观众不愿继续，即停止；不连续刷新。

交接｜记录时间、区域、入口、可见错误和尝试结果 → 现场负责人；多设备同入口异常则暂停该入口邀请。

E2 / NFC 或二维码无法打开

现象｜轻触无响应，或扫码无法识别、跳转失败。

先查｜确认卡片对象、二维码是否遮挡及目标链接；不要求观众安装不明应用。

替代｜NFC 失败改用同对象已核实二维码；二维码失败仅用负责人提供并核实的备用链接。

停止｜替代入口仍失败或没有已核实替代路径，停止；不临时编造链接或把其他产品入口当备用。

交接｜记录触点编号、NFC / 二维码类型、现象与结果 → 现场负责人核对物料和入口。

E3 / 页面对象不对应

现象｜名称、产品图或活动场次与观众想反馈的对象不同。

先查｜核对实物、卡片、页面三处身份，先停止填写。

替代｜无内容时转已核实正确入口；已有内容先说明重新打开可能丢失，由观众决定是否继续。

停止｜正确入口仍错配，或找不到目标对象，即停止。不得把意见提交给错误对象。

交接｜记下入口编号和错误 / 目标对象 → 现场负责人暂停该物料，交技术支持检查映射。【待确认】草稿跨入口迁移。


# 结果不明确时，先停止重复提交

【界面】为当前模拟行为；【待确认】为真实服务能力；其余恢复与停止规则为现场拟定。

先判断：现在看到什么状态？
语音不可用 → 转文字 → E4；明确显示失败 → 确认能安全重试 → E5；没有明确结果 → 停止重复提交 → E6

E4 / 语音不可用、无内容或转写失败

现象｜显示语音不可用、No words picked up 或转写错误。

先查｜【界面】先看是否标有 simulated；当前演示不请求麦克风、不录音、不做真实转写。

替代｜【界面】Write instead 转文字；已有文字保留。演示可点 Try voice again / Try again 测试恢复。

停止｜一次恢复后仍失败或观众不愿说，就转文字或结束，不反复要求授权。

交接｜记录页面提示及切换后是否完成 → 现场负责人；【待确认】真实权限、浏览器兼容与转写能力由技术支持核实。

E5 / 明确显示提交失败

现象｜页面明确显示错误并提供重试入口。

先查｜【界面】当前演示保留草稿，可在原页重试；这是模拟行为，不等于真实系统确认未接收。

替代｜真实现场先按负责人确认的失败语义处理；仅在已确认可安全重试时，由观众选择重试。

停止｜一次安全重试仍失败，或接收状态不确定，停止并转 E6。

交接｜记录报错、点击时间、重试次数与最后状态 → 现场负责人 / 技术支持。【待确认】超时语义和重复提交去重。

E6 / 完成状态不明确

现象｜点击后一直等待、页面关闭、断网，或没有明确完成提示。

先查｜不要把“无成功提示”视为“未提交”。先询问最后一步、可见状态及是否已点过提交。

替代｜保持原页，不刷新、不重开重复提交；允许观众结束等待。负责人再请后台核查。

停止｜无法由已确认机制判断时就停止操作，记录“结果不明确”；不要求观众无限等待。

交接｜记录时间、入口、最后动作和页面状态；有系统回执编号才记编号 → 负责人交后台核实。当前演示无真实接收查询。

交给谁 / 如何闭环【现场拟定】

工作人员 → 现场负责人汇总；入口、网络和语音故障 → 技术支持；提交状态 → 后台团队；对象、活动名称和问题文案 → 区域内容负责人。实际人员和联系方式见第 8 节。

同一入口连续出错、对象错配或出现意外个人信息，立即联系负责人；其他记录按约定班次交接。接收人确认收到，填下一次回查时间，解决后补依据，不以“已转发”当关闭。
