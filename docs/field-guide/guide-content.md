# 帮助表达，不替人作答

先听，再给一次中性提示；接受原有回答，也允许随时结束。

## 01 不知道 YouFeed 是什么
说明用途与参与方式。
这是一个反馈入口，帮助我们了解您对这里的看法。是否参加由您决定。
只介绍已确认的用途，不承诺奖励或意见一定获采纳。

## 02 不知道该评价什么
确认对象，缩小范围。
这里对应[对象]。您可以只说最有感受的一点。
不提供示例答案，不说“可以夸一下设计”。

## 03 “没意见”或评价笼统
提供一次自愿补充的机会。
如果愿意，可以说说为什么；不补充也可以。
不反复追问，不将“还行”改写成好评。

## 04 不方便使用语音
直接提供文字选择。
您可以选择文字输入，按自己的方式写。
不要求先开麦，不代录、不代答。

## 05 进入错误对象页面
停止错配，核对入口。
您想评价的是[目标对象]，对吗？我们先核对入口。
不在错误页面硬填；已有文字先说明丢失风险。

## 06 不愿参与或想结束
尊重退出，结束协助。
好的，谢谢您，您可以随时结束。
不劝留、不追问原因、不替其完成。


# 先分清状态，再恢复连接

先问：有没有写下内容？有没有点过提交？不要一律刷新重试。

尚未填写 → 核对入口 / 网络

已写，未提交 → 保留原页 → E1

已提交 / 不确定 → 不重复提交 → E6

E1 / 网络不稳定或页面打不开

先问 / 确认是否已有文字、是否点过提交，再检查网络与入口。

未填写 / 可自愿切换可用网络，重新打开已核实入口。

已写未交 / 保留原页，不刷新、不清空。告知观众内容尚未提交；按已确认的草稿恢复方式处理，或由观众选择结束。不要转去核查接收。

已提交 / 若已点提交或无法确认，转 E6；不重新打开重复提交。

停止 / 交接 / 一次有变化的恢复尝试仍失败，或观众想结束，就停止。记入口、状态与尝试结果，交现场负责人。

E2 / NFC 或二维码无法打开

先查 / 核对卡片对象、二维码遮挡和目标链接。

替代 / NFC 失败可用同对象已核实二维码；二维码失败，仅用负责人提供并核实的备用入口。

停止 / 交接 / 替代入口仍失败或没有备用入口，就停止；记触点编号与现象，交负责人核对物料。

E3 / 页面对象不对应

先查 / 对照实物 / 活动牌、物料和手机页面，停止填写。

替代 / 未填写时转正确入口；已有文字先说明重新打开可能丢失，不承诺自动迁移。

停止 / 交接 / 找不到正确入口或仍错配，暂停该物料；记错误与目标对象，交负责人处理。


# 结果不明确时，不重复提交

按可见状态处理；只有已确认安全时，才邀请观众重试。

语音不可用 → 转文字 → E4

明确失败 → 安全重试？→ E5

接收不明确 → 不重复提交 → E6

E4 / 语音不可用或转写失败

先查 / 读取页面提示，确认是否已有文字。

替代 / 提供文字输入；按页面提示保留已有内容。仅在该版本已确认支持时尝试语音恢复。

停止 / 交接 / 一次恢复仍失败或观众不愿继续，转文字或结束；记录提示和切换结果，交负责人。

E5 / 明确显示提交失败

先查 / 读取错误提示，按负责人确认的失败语义判断；报错不一定意味着后台未接收。

替代 / 仅在该错误已确认可安全重试时，由观众选择重试。

停止 / 交接 / 一次安全重试仍失败，或接收状态不确定，转 E6。记时间、重试次数及最后状态，交负责人。

E6 / 已提交，但接收状态不明确

先查 / 确认最后动作和页面状态；无成功提示不能直接视为未提交。

当场 / 原页仍在就保留，不刷新、不重开重复提交。说明结果暂不明确，允许观众结束等待。

停止 / 交接 / 不继续试交。记时间、入口、最后动作及系统回执号（如有），由负责人交后台核查。

状态 / 记录“结果不明确”，核查后再更新；没有确认机制时，不向观众声称已接收。

所有恢复规则由负责人在第 08 节确认；未确认的能力不作现场承诺。
